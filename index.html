USER HELP CENTER

Help & Support

Guidance for using Val Specialism from account setup to validation and reporting.

Getting Started

Create an account first, then log in with the registered email and password to access the workspace.

Account & Login

Use the exact email and password used during signup. An unregistered email or incorrect password will not allow access.

Upload Source File

Upload the client/source spreadsheet in CSV, XLSX, or XLS format. This is the dataset you want to validate.

Upload Reference File

Upload the reference/comparison spreadsheet in CSV, XLSX, or XLS format. Both files are required before configuring validation.

Match Key Fields

Select one or more fields that identify the same record across both datasets. Multiple selected fields form a composite match key.

Fields to Compare

Select the fields that should be checked after matching records. Text, numeric, date, and blank-value differences are reported exactly.

Run Validation

After both files and required fields are selected, run validation to identify mismatches, missing records, reference-only records, blanks, and duplicate keys.

Validation Results

Review the record-level findings and summary counts for rows checked, matched records, total issues, high-severity issues, and missing/reference-only records.

Standardized Issue Log

Review each finding with its row, key, field, issue type, source value, reference value, severity, and standardized reason.

PDF Export

After validation, use the PDF export option to generate the formatted Validation Report containing the summary and standardized issue log.
